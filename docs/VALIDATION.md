# 验收说明

记录日期：2026-11-08。主要环境：Windows 11、Python 3.12、16 GB 内存、NVIDIA RTX 4060 Laptop 8 GB。以下为一台机器和一份代表性材料的结果，不代表其他硬件的最低配置或所有音频的准确率。

## 真实模型验收

先前阶段已完成一段约 55 分钟英文视频的代表片段与整片转写，得到 768 个段落、2 个声音分组。第六阶段复用这份文字稿，不重复转写；原始视频、文稿和测试日志不进入公开仓库。

最新摘要验收在完成两段后主动停止，再用另一个进程继续：

| 检查 | 结果 |
| --- | --- |
| 停止前用时 | 32.234 秒，保存 2 段 |
| 新进程继续用时 | 74.547 秒，复用 2 段 |
| 两次运行合计 | 106.781 秒，包含两次启动 |
| 实际推理设备 | Vulkan GPU，37 / 37 层卸载 |
| 缓存保护 | 已提交分段的哈希和修改时间不变 |
| 文稿保护 | 原文稿文件、文字段落和说话人不变 |
| 最终摘要 | 7 条中文要点，来源时间覆盖前、中、后段 |
| 逐字引文 | 1 处时间修正，未核实引文 0 条 |

摘要使用结构化字段区分中文概括和原文引句，先快速生成并校验，只对格式失败做一次约束重试。合并后从分散在全文各处的分段保留要点，避免只截取开头；超过摘要条目容量时仍会取舍，不承诺涵盖每个细节。

## 性能对照

第五阶段同一份文字稿的 CPU 路径为 1250.59 秒，GPU 路径为 94.797 秒。固定 69-token 输入、128-token 输出另测 CPU 16.359 秒、GPU 约 2.0 秒，约 8.2 倍提速。

第六阶段增加了格式校验、必要重试和恢复缓存，当前记录为上述停止/继续测试。不同版本、生成长度、缓存和模型加载状态会影响结果；不能把不同输出的耗时当成严格控制变量的性能对比。

## 界面与回归

最终公开源码副本完整回归：**243 项全部通过，216.502 秒**。该副本不含模型、私人文稿或本机运行目录；测试解释器使用本机已有依赖。

以上为本机验收结果。GitHub Actions 尚未启用，仓库提供可手动启用的回归模板，方法见 [贡献说明](../CONTRIBUTING.md)。

界面使用合成演示文稿，在 1240×820 并排布局、960×680 单栏布局和宽屏专注阅读模式检查可读性与操作可达性。公开截图只捕获测试程序自己的窗口，不包含用户桌面或私人文稿。

回归入口为 `python -B -m unittest discover -s tests -v`，覆盖保存冲突、任务归属、取消恢复、自动语言路由、搜索回听、摘要版本、GPU 回退与缓存隔离。普通回归使用模拟引擎和合成材料；真实模型测试通过 `tests/validate_summary_recovery.py` 显式运行，不纳入 GitHub 自动回归。

## 如何理解结果

没有人工逐字标注的参考答案，因此不报告词错误率或说话人准确率。时间引用检查可以识别不存在的时间；逐字引文检查可以匹配原文并校正位置。中文概括的事实、语义对应关系及精确定位仍需人工核对：实测中有要点只指向附近话题。系统明确显示“要点需核对原文”，不会将机器校验等同于事实确认。

仅验证上述 Windows / NVIDIA 环境。CPU 回退逻辑有自动测试，完整 CPU 摘要有前阶段基线；第六阶段未再次等待整份 CPU 摘要。其他操作系统、显卡、混合语言和复杂重叠说话场景不在本轮实测结论范围内。
