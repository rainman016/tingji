# 逐字稿工作台设计规范

2026-11-09 用户确认：采用 14px 预览的风格与字号，去掉摘要，交付本地手测后再确认 GitHub 更新。

- 任务顺序：导入音视频 → 确认名称和语言 → 真实转写进度 → 阅读、搜索、回听、校对 → 导出。
- Microsoft YaHei：标题 20px 常规字重，正文 14px，按钮 13px，段落元信息 12px；可放大到 16px。原生 Tk Text 使用负像素字号，并跟随 CTk 显示缩放。正文行高目标 1.65。
- 深石墨侧栏 #171D26、冷白画布 #FAFBFD、正文 #18222E、青色操作 #087F8C、选中底色 #EDF6F7。色彩承担导航、状态与焦点作用。
- 文稿始终使用单阅读面；资料库显示名称、语言、时长和日期。导入、转写选项与偏好设置采用右侧面板，Escape 关闭，Tab 在当前面板内循环；下拉菜单关闭后恢复面板焦点约束。
- 标题改名内联完成；段落校对在原位置展开，明确保存和取消。切换前提交有效校对，空文本和保存失败阻止离开。保留并发版本保护。
- 底部回听条对应实际分段播放能力，附近时间按钮跳至真实段落；不展示伪波形、虚构进度或未实现的播放速度。
- 校对规则只有一条：离开段落即保存，Esc／取消即放弃。校对中输入搜索词只高亮不跳段，Ctrl E 与说话人改名不提交正文草稿；放弃后按 Ctrl Z 可恢复刚才的草稿。校对框高度随内容变化（3～8 行），保存与取消固定在底部。
- 停止或中断的任务面板标题为“已停止 · 可继续”，步骤条停在“生成逐字稿”，“继续转写”在主操作位，“重新转写”为弱按钮。等待确认语言时，未选择中文或英文不能继续。
- 图标由本地矢量构形代码 studio_icons.py 绘制，24 格栅、单一线宽、圆头单线；只有品牌标记是填色的圆角块加声波条。2026-11-10 手测否定了原先的错位轮廓、双层填色和信号点（小尺寸下发糊）。程序图标 assets/tingji-studio.ico 由 `python studio_icons.py` 生成。按钮提供文字或键盘操作。不依赖在线资源。
- 演示文稿使用固定编号，重复打开回到同一份，不在文稿库产生副本。
- 摘要没有入口、不自动运行、不出现在常规导出；历史数据保留。旧摘要工具与测试仅作兼容用途。
- 验收覆盖 1240×820、960×680、125% 缩放、775 段长文稿、空状态、导入、语言确认、失败、恢复、保存冲突和键盘操作。截图来自真实原生窗口，使用演示数据。
