# 听记界面约定

用户导入一段录音后，需要长时间读稿、核对原音、修正信息，再把结果交付给他人。以阅读工作台为主，任务状态服务于正文。

领域元素为录音、文稿、时间戳、说话人、引文、校对与资料库。时间戳是贯穿阅读、回听和摘要定位的统一入口。纸白正文、墨绿操作、铅灰说明、浅灰绿选中、琥珀待核对状态构成色彩方向。

沿用原生 Windows 与 CustomTkinter 控件；不用统计卡片占据读稿空间，也不把摘要包装成聊天记录。长正文默认收起设置和校对面板，按任务需要展开。

- 主题颜色与字体集中在 `ui_theme.py`；正文、辅助信息和操作状态按层级区分。
- 文稿标题 26 px、摘要标题 20 px、控件 14 px、辅助信息至少 13 px；原生正文 14 pt、摘要正文 13 pt、摘要章节 15 pt。区分 CTk 的像素字号与原生 Text 的点字号。
- 间距以 4 像素为基准；面板通常 12～16 像素内边距，功能组之间留更大间隔。
- 1240×820 默认正文与摘要以 6:5 并排；960×680 单栏切换；宽屏提供“专注阅读”，窄屏隐藏不适用的布局按钮。
- 导出集中到右上角的原生菜单，保留 TXT、SRT、Markdown、JSON 四种格式。回听与校对跟随当前段落，运行设置默认折叠。
- 摘要默认使用只读排版视图，区分概览、要点、行动与原文引文。阅读视图隐藏标题和强调语法，原始 Markdown 与导出内容不变；点击“编辑摘要”进入原文编辑，修改自动保存，“完成编辑”返回阅读。保存失败时保留编辑视图。
- 中文段落采用连续文字换行，英文段落按单词换行。摘要时间只对通过来源检查的引用开放跳转；点击、Alt+上/下与 Enter 均可操作。
- 按钮支持 Tab、Enter、空格，焦点可见；不依赖颜色表达处理中、失败或待核对。
- 每次版式修改用合成文稿捕获本程序窗口，检查空白、长文、窄屏和操作可达性。
